# 比特浏览器接入本地测试记录

日期：2026-10-14。版本：3.2.0。源码回归、真实 API、图文发布前流程、窗口关闭和界面按钮检查通过；用户确认测试完成后已生成最终安装包、更新包和独立更新器。包体验收见 `BUILD_VERIFICATION_v3.2.0.md`。本轮实机验证未执行最终提交。

## 最终行为

- 队列支持快捷方式/EXE 与比特浏览器混排；比特账号配置 API 地址、窗口 ID 和可选 Token，支持分页查询及搜索选择。
- 先查 /browser/pids/alive；已有窗口通过 /browser/ports 取得调试端口直接连接，不调用 /browser/open。仅窗口未打开时启动一次，打开请求不自动重试，调试地址异常不自动关闭重开。
- 开始任务前关闭所选比特窗口的默认工作台和多余标签，只留一个发布标签。优先复用创作者页，其次复用普通标签；仅剩工作台或没有标签时才新建一次。后续作品和重试使用同一页。
- 默认勾选“任务结束后关闭调用的比特窗口”。同一窗口还有重复队列项或轮换批次时继续复用，最后一项发布任务结束后按 ID 关闭，包括被任务复用的预先打开窗口。失败、手动停止及异常结束清理本次调用的比特窗口；仅登录检查保留窗口。
- 关闭后遵守官方 5 秒间隔；不调用关闭全部窗口或批量结束同名进程。包含比特账号的队列跳过全局 Chrome 残留清理。
- 发布页就绪等待默认最长 120 秒，可设置 1—600 秒；提前就绪立即继续。
- 上传声明弹窗默认选择“无需添加自主声明”并确认；点击限定在声明弹窗内，并回读选中状态和弹窗关闭。账号显式启用的声明仍在发布前选择并校验。
- Token 通过 x-api-key 发送，按 API 地址使用 Windows DPAPI 加密保存到 %LOCALAPPDATA%\DouyinPublisher\bitbrowser_api_tokens.bin。不进入配置 JSON、队列 Excel 或 worker 临时配置，不跟随 HTTP 重定向，错误中的当前 Token 被隐藏。
- 保留旧队列 ID、账号独立状态路径、配额、排期、图片和文案规则。
