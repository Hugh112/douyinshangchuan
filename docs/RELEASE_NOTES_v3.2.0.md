# v3.2.0 发布说明

比特浏览器窗口现在可以加入图文发布队列，与已有快捷方式账号顺序或轮换执行。填写本地 API 地址后可读取并选择窗口；开启鉴权时填写 Token，Token 按 API 地址使用 Windows DPAPI 保存在本机。

- 已打开窗口直接查询动态 CDP 端口并复用，未打开时只调用一次打开接口。任务开始先关闭默认工作台和多余标签，只保留一个发布页；同一窗口的重复队列项和轮换批次继续复用，最后一项任务结束后按窗口 ID 自动关闭。登录检查保留窗口。
- 发布页最长加载等待默认 120 秒，可设置 1—600 秒，提前就绪立即继续。上传声明弹窗默认选择“无需添加自主声明”；账号显式配置的声明仍在提交前选择并校验。
- 修复浏览器编辑窗口保存按钮被遮挡：底部保存/取消始终保留，三个标签页独立滚动。主界面队列操作和任务控制分两行；登录、本地 API 填写窗口适配可用屏幕与缩放。
- 保留 3.1.3 话题活动节点及快速选择修复、账号独立文案/图片/排期、队列进度和重试能力。更新器版本及 EXE 元数据同步为 3.2.0。

2026-10-14 用户确认本地测试完成并授权打包。48 项回归、258 项按钮检查、包内容/哈希、隔离安装和 3.1.1 原更新器跨版本更新通过。本轮比特实机验证完成 12 项发布前步骤和窗口生命周期检查，未提交真实作品。

安装包、更新 ZIP 和独立更新器已生成；详细哈希见 `BUILD_VERIFICATION_v3.2.0.md`。根目录 `version.json` 记录本地候选元数据，云服务器及统一后台尚未投放。GitHub 用于源码备份。
