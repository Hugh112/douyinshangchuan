# v2.5.1 更新说明与验收记录

发布日期：2026-08-05

## 主要变化

- 同一浏览器可以在账号队列中重复出现；重复行具有独立队列 ID、内容、发布时间和发布进度。
- 每个队列项单独选择立即发布或定时发布；公共抖音发布时间和公共内容输入已从界面取消。
- 本轮实际条数只取队列行的“发布条数”，不再受旧全局上限或排期槽数量静默截断；定时槽不足会明确阻止启动并提示。
- 修复无表头 Excel 第一条文案被当成表头跳过的问题，并确保读取、删行后及时释放工作簿。
- “等待与检测”和“运行选项”移到发布中心，失败重试次数归入“等待与检测”；第二标签改为“账号与排期”并扩大队列表。
- 浏览器队列新增完整 Excel 全表导入、导出和复制队列项功能。
- 授权恢复或登录成功后才显示发布配置主界面；退出、切换失败或授权撤销后回到登录门禁。
- 四个标签各自使用独立滚动容器，滚动互不影响；浏览器账号表格增加横向和纵向滚动。
- 任务控制固定到运行日志区域，任意标签都能看到；移除不必要的小字说明。
- 统一后台更新策略为空或不完整时，可靠回退 GitHub Raw，再回退 jsDelivr。
- 安装向导始终显示安装位置，允许用户自定义目录。
- 构建脚本不再在仓库根目录留下 SPEC，并在成功后清理临时缓存。
