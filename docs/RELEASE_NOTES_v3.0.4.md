# v3.0.4 更新说明

发布日期：2026-08-10
更新策略：可选更新，不强制升级

## 本次修复

- 修复抖音页面已经选中“定时发布”，但程序因新版单选控件状态不可读而误报“没有成功点击定时发布”的问题。
- 点击定时发布后必须等待“发布时间”输入框真实出现；未出现时停止该步骤，不会继续提交。
- 时间输入严格执行“读取旧值 → 清空 → 写入账号排期目标时间 → 回读确认”的顺序。
- 键盘不适用于只读或受控日期组件时，自动使用 v3.0.1 已验证的 DOM 原生输入逻辑，不再跳过时间写入。
- 设置步骤和点击底部发布按钮前各校验一次目标时间；任一回读不一致都禁止发布。
- 继续保留 v3.0.3 的任务控制按钮布局和发布页已到底部时跳过滚轮优化。

## 真实页面验证

已在测试浏览器账号的抖音图文发布页完成两次真实输入验证：程序识别可见定时框，清空旧值，分别写入目标时间并成功回读。测试过程没有点击底部发布，不消费图片、文案或任务进度。

## 2026-08-10 同版本热补丁

- 修复未勾选定时发布时仍点击并校验“立即发布”单选框，导致新版控件误报失败的问题。
- 未启用定时发布的账号现在跳过发布模式设置，完成图片、标题、正文和音乐等最终校验后，直接点击底部真正的“发布”按钮。
- 已安装 v3.0.4 的用户可运行 `DouyinPublisher_Hotfix_v3.0.4.exe`；补丁只替换主程序，不修改任何用户数据。
