# v2.5.2 更新说明与验收记录

发布日期：2026-08-06

状态：正式稳定版；GitHub 与统一管理后台均采用非强制更新策略。

## 主要变化

- 停止任务或关闭软件后保留未完成的队列轮次；再次启动时跳过本轮已处理账号，当前账号仅发布剩余条数。
- 兼容 2.5.1 仅保存 `slot_index` 的状态文件，例如配额 75、已完成 64 时升级后继续剩余 11 条。
- 排期修改只调整定时时间点，不清除本轮已完成条数；只有“重置发布进度”会清空文案、排期和队列轮次进度。
- 状态文件使用同目录临时文件原子替换，降低强制停止过程中状态文件损坏的风险。
- 暂停、继续、停止和重新启动统一处理基础状态及账号独立状态的暂停标记，避免遗留暂停标记阻塞续跑。
- 账号与排期表格关闭自动列伸缩；用户手动拖动后的每列宽度写入配置并在下次启动恢复。
- 完整包含 2.5.1 本地热补丁：排期时间点不足时循环复用；账号队列只有勾选行参与检查、统计和发布。

## 从 v2.3.0 升级可见的主要功能

- 从脚本/VBS 主启动方式升级为原生 `DouyinPublisher.exe` 和可自定义路径的完整安装包，运行依赖随安装包提供；固定名 VBS 仅保留给旧快捷方式兼容。
- 接入统一授权：支持软件账号登录、记住账号、DPAPI 加密记住密码、切换账号、定时心跳、授权变化即时暂停和脱敏遥测。
- 多浏览器账号按队列顺序发布；同一浏览器可重复出现，每行可独立设置发布条数、图片、Excel、工作表和立即/定时排期。
- 只有勾选的队列行参与任务；掉号或无法进入发布页时自动跳过并切换下一个账号，全部账号处理后才结束。
- 每个账号使用自己的内容和发布进度；支持队列 Excel 全表导入/导出、排期时间点循环复用、停止或重启后从剩余条数续跑。
- 支持按星期和时间自动启动；任务控制与运行日志在所有页面固定可见，各页面独立滚动，队列表列宽按手动调整结果保存。
- 修复 Excel 第一条文案、逐字输入正文与话题、多余 `#`、正文误判、作品管理页判断、失败重试和任何自动暂停均弹窗等发布稳定性问题。
- 在线更新改为统一管理后台优先、GitHub Raw 备用、jsDelivr 最后备用；更新包下载后必须通过 SHA256 校验并保留用户配置。

本次为可选更新，不强制升级。软件账号和密码请自行联系各组组长获取。

## 验收重点

- 中途停止配额任务，重启后确认已完成账号不重发、当前账号只发剩余条数。
- 完成整轮后再次开始，确认会创建新的完整轮次。
- 拖动账号表各列宽度，切换标签和重启软件后确认保持不变。
- 验证勾选账号过滤、75/57 排期循环、授权心跳、遥测、失败重试和自动暂停弹窗未回退。
