# v3.0.1 城市图片识别修复说明

## 修复内容

- 修复 Excel 城市列未被识别时只检查图片总目录根层、无法进入城市子文件夹的问题。
- 新增“城市栏、城市列、城市名称、地市、所属城市、素材城市、图片城市”等常见表头兼容。
- 新增无表头 `城市 | 文案`、`城市 | 标题 | 文案` 多列兼容；旧无表头单列仍读取第一列且不遗漏第一条。
- 允许 Excel 中的“济南市”匹配图片总目录中的“济南”子文件夹；仍只匹配总目录的直接子文件夹。
- 未识别城市列但发现城市子文件夹时，显示明确的 Excel 格式提示。
