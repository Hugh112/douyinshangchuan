# 抖音智能发布中心 v3.0.10 更新说明

## 城市图片目录修复

- 第一优先级始终查找与 Excel 城市原文同名的直接子文件夹。
- Excel 单元格带有不可见字符或特殊空白时，会先清理这些字符，再进行规范化同名匹配。
- 图片文件夹刚新增、目录缓存未自动失效时，会先刷新并重新查找同名目录，之后才允许行政后缀或地级市/区县别名匹配。
- 修复“庆阳西峰区”等同名目录实际存在，但程序仍提示找不到对应图片子文件夹的问题。

## 多图规则

- 一条作品的一次上传中，N 张图片互不重复。
- 同一批次的多条作品之间允许重复使用相同图片；例如 75 条任务可以使用完全相同的一组图片。
- 未勾选“发布成功后删除图片”时，后续作品继续从完整图片库选择。

本候选包未修改线上更新清单或统一管理后台，需完成测试后再推送。
