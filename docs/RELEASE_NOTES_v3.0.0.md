# v3.0（内部版本 3.0.0）更新说明与验收范围

## 新功能

- Excel 新增“城市、标题、文案”三列识别；标题可空，文案不能为空。
- 城市按名称匹配共享图片总文件夹下的同名子文件夹，图片只从文件系统读取，不读取 Excel 内嵌图片。
- 所有浏览器账号共享图片池；每个队列项继续使用自己的 Excel、工作表、发布条数和独立排期。
- 标题、正文和话题均通过浏览器键盘事件逐字输入，不占用剪贴板。

## 兼容性

- 无表头单列 Excel 的第一行仍是第一条文案。
- 有“文案”表头的旧文件继续支持。
- 历史单列以“标题”为表头的文件继续按旧文案列表处理。
- 没有城市列时继续从图片总文件夹根目录选择图片。
- v2.5.2 的排期循环、勾选队列、任务续跑、列宽保存、失败重试和自动暂停弹窗全部保留。

## 发布物

- 在线更新包：`DouyinPublisher_Update_v3.0.0.zip`
