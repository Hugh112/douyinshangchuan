# 抖音智能发布中心 v3.0.8 更新说明

## 新增功能

- 每个浏览器账号可单独设置一条作品上传 1—35 张图片。
- 每个账号可选择随机取图或按图片名称顺序取图；同一批次不重复，成功使用过的图片不会再次选中。
- 每个账号可选择是否填写发布声明，并可在前端自行修改“声明入口文字”和“声明内容”。
- 声明内容支持下拉快速选择，也支持直接输入抖音页面当前显示的完整文案。

## 安全与兼容

- 发布失败、步骤重试或总体重试不会消费图片；同一作品总体重试继续使用同一图片批次。
- 只有确认进入作品管理页后，才记录已用图片、删除图片/文案并增加发布进度。
- 旧账号配置自动兼容为每条 1 张图片、沿用原随机图片设置、默认不启用声明。
- 保留多浏览器、轮换发布、城市图片、标题列、旧无表头 Excel、定时发布、暂停恢复、失败原因和在线更新进度等现有功能。

## 使用方法

1. 打开“账号与排期”，选择账号并点击“编辑”。
2. 在“图片与声明”页设置每条图片数以及随机/名称顺序。
3. 如需声明，勾选“启用并在发布前选择声明”，填写平台当前显示的声明入口和声明内容。
4. 保存账号和总配置后开始发布。

本包为 v3.0.8 本地候选包；在真实账号与异机测试通过前不修改线上推送策略。
