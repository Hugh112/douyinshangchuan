# v2.5.1 更新说明与验收记录

发布日期：2026-08-05

## 主要变化

- 授权恢复或登录成功后才显示发布配置主界面；退出、切换失败或授权撤销后回到登录门禁。
- 四个标签各自使用独立滚动容器，滚动互不影响；浏览器账号表格增加横向和纵向滚动。
- 任务控制固定到运行日志区域，任意标签都能看到；移除不必要的小字说明。
- 统一后台更新策略为空或不完整时，可靠回退 GitHub Raw，再回退 jsDelivr。
- 安装向导始终显示安装位置，允许用户自定义目录。
- 构建脚本不再在仓库根目录留下 SPEC，并在成功后清理临时缓存。

## 成品

最终文件名和 SHA256 以根目录 `version.json` 及 GitHub Release v2.5.1 为准。

- 安装包：`DouyinPublisher_Setup_v2.5.1.exe`
- 在线更新包：`DouyinPublisher_Update_v2.5.1.zip`
