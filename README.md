# 抖音智能发布中心

当前线上稳定版：`v3.0.7`（网页崩溃恢复、音乐入口实效校验、轮换文案去重、图片目录缓存与平台失败原因采集），于 2026-09-03 按 100% 灰度、非强制策略正式发布。

Windows 桌面端抖音图文自动发布工具。当前版本已接入统一授权后台，支持多浏览器账号按队列发布、账号专属内容、定时启动、运行遥测和安全在线更新。视频发布与 AI 内容生成属于后续版本范围，本版不包含这两项。

## 当前能力

- 软件账号登录、退出、切换账号、记住账号和 DPAPI 加密记住密码。
- 每次登录或受保护会话恢复时在线验证一次；本次登录期间固定使用授权快照，不再定时请求授权心跳或隐式刷新。
- 多浏览器账号独立配置、发布配额、独立 Excel/工作表/发布时间、掉号跳过和顺序切换；同一浏览器可重复加入队列。
- 可选账号轮换发布，并自定义每个账号连续成功发布几条后切换；各账号按自己的剩余配额精确收尾。轮换保留多个 Chrome 时，没有显式用户目录的快捷方式会按快捷方式和端口使用独立持久目录，避免端口被同一 Chrome 实例吞并。
- 所有账号共享一个图片总文件夹；新表格可用“城市、标题、文案”三列表头，图片子文件夹支持市、州、自治州、区、县、自治县、盟、旗等带/不带后缀匹配，标题为空时保持旧发布方式。
- 发布条数只由每个队列项的“本轮发布条数”决定；日期、小时和每小时条数仅用于生成该行的定时时间点。
- 浏览器队列支持完整 Excel 表格导入和导出；每一行使用独立状态文件记录文案与排期进度。
- 停止任务或重启软件后继续未完成的队列轮次：已完成账号跳过，执行中账号只发布剩余条数；仅“重置发布进度”会清零。
- 账号队列表支持勾选发布、排期时间点循环复用，并持久保存用户手动拖动的列宽。
- 随机图片或按文件名排序取第一张图片。
- 仅允许读取 `.xlsx`、`.xls`、`.xlsm` 文案文件；旧无表头单列和旧“标题”单列表头均会正确使用第一条文案。
- 正文和话题使用浏览器键盘事件逐字输入，不占用剪贴板。
- 立即发布、抖音定时发布、多日排期、按星期和时间自动启动。
- 失败时先按前端配置只重试当前步骤；步骤仍失败后再按前端配置总体重跑当前作品，最后记录具体原因、保留进度并跳过账号。
- 浏览器控制优先使用 Playwright 语义定位与 DOM 模块直控，真实鼠标和坐标仅作逐级兜底；图片上传、音乐、发布设置和提交后都校验网页实际状态。
- 音乐已生效时直接跳过；未生效时先使用新版语义/DOM 定位，严格确认真实音乐抽屉后才读取列表；新版模块无法打开抽屉时，完整执行 v3.0.1 音乐行识别、右侧区域和文字矩形真实点击流程。歌曲列表继续使用新版识别规则。
- 可一键重试当前勾选的失败、掉号或今日上限账号，继续原内容与累计进度。
- 检测到今日投稿上限后不消费内容、不增加进度，按前端等待时间切换账号；调试截图每三次正常启动清理一次本软件生成的旧截图。
- 暂停、继续、停止、重置进度和全局可见运行日志；进度或日志字段误选为目录时，在目录内自动使用固定 JSON/CSV 文件名。
- 原生 `DouyinPublisher.exe` 无黑框启动，安装包内置运行依赖并支持自定义安装路径。

## 正式代码

- 主程序：`app/app_main.py`
- 同步入口：`app/app_main.pyw`，内容必须与主程序完全一致
- 授权客户端：`app/platform_auth.py`
- 在线更新器：`app/online_updater.py`
- 用户配置：`app/douyin_gui_config.json`，仅保留在用户电脑，不提交 Git
- 构建脚本：`build_release.ps1`
- 安装器定义：`installer/DouyinPublisher.iss`
- 更新清单：`version.json`

安装版把配置、授权会话和登录偏好存放在 `%LOCALAPPDATA%\DouyinPublisher`，不放入安装目录，因此升级或更换安装路径不会覆盖这些数据。

## 更新来源

客户端按以下顺序检查：

1. 已授权时优先读取统一管理后台 `publisher.douyin` 的稳定通道策略。
2. 后台不可达、未配置版本或返回的新版本策略不完整时，回退统一云服务器静态清单。

更新清单和更新包均使用 `https://api.xibao-zg.top/updates/publisher.douyin/` 云服务器通道；GitHub 只备份源码，不再作为客户端更新下载源。更新器显示下载、SHA256 校验、解压、安装和重启进度，并继续执行 ZIP 路径安全检查和用户配置保留。

## 构建

在 Windows PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build_release.ps1
```

构建结果：

- `release/DouyinPublisher_Setup_v3.0.7.exe`
- `packages/DouyinPublisher_Update_v3.0.7.zip`

构建脚本会把依赖冻结到安装目录，并在成功后清理临时 `build`、`.spec`、`__pycache__` 和 `.pyc`。

详细维护信息见 [交接文档](docs/HANDOVER.md) 和 [更新发布文档](docs/UPDATE_GUIDE.md)。
