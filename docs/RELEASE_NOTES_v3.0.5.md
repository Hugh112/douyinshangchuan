# 抖音智能发布中心 v3.0.5 更新公告

发布日期：2026-08-11

本次为可选更新，不强制安装。

## 修复内容

- 修复个别浏览器首次启动较慢时，调试端口尚未就绪便被判定失败；进程已启动时会继续等待，进程未启动时只重试浏览器启动步骤一次。
- 修复账号第二轮已经正常发布，队列表仍显示上轮“失败已跳过”的问题；累计进度继续保留，运行状态按当前任务实时刷新。
- 优化音乐抽屉识别。加载中的抽屉不再被当作未打开，优先点击音乐行右侧真实操作控件，并等待歌曲列表实际就绪。
- 合入 v3.0.4 立即发布补丁：账号未启用定时发布时直接点击底部发布按钮，不再操作“立即发布”选项。
- 在线更新改用统一云服务器下载，减少 GitHub 下载失败；更新包仍执行 SHA256 和 ZIP 路径安全校验。

## 保留行为

- 不清零账号累计发布进度，不消费失败作品的图片或文案。
- 不修改用户浏览器、图片、Excel、日志、状态和调试截图目录。
- 仍支持多账号、轮换发布、独立排期、城市图片、标题列、旧无表头 Excel、暂停恢复和失败账号重试。
