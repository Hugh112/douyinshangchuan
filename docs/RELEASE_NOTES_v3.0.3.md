# v3.0.3 更新说明

发布日期：2026-08-10
更新策略：可选更新，不强制升级

## 本次修复

- 修复任务控制区按钮在常用窗口宽度下被右侧裁切的问题，“重置发布进度”和“清空日志”现在始终位于日志操作区并完整显示。
- 修复选择“定时发布”后目标日期时间未实际写入的问题：程序会用真实键盘输入完整时间，并在失焦后回读输入框确认；失败时继续使用原日期面板与 DOM 事件兜底。
- 优化发布页底部定位：如果发布设置、发布时间和底部发布按钮已经可见，立即跳过下滑、鼠标滚轮和等待。
- DOM 下滑到位后不再追加鼠标滚轮；只有网页内部滚动容器仍未到位时才执行真实滚轮兜底。

## 继续保留

- 多浏览器队列、账号轮换、账号独立 Excel/排期/进度、失败账号重试和暂停后编辑队列。
- 城市图片子文件夹、标题列、新旧 Excel 格式、随机图片和逐字输入正文/话题。
- 分层步骤重试、音乐状态校验、今日投稿上限切换、掉号跳过和作品管理页成功确认。
- 登录授权、记住账号密码、定时心跳、遥测、SHA256 在线更新和用户数据保护。
