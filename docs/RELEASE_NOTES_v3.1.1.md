# 抖音智能发布中心 v3.1.1 发布说明

## 话题关联方式修复

- Excel 中的 `#话题` 写法保持不变。
- 发布时先输入纯正文，再逐个点击网页“添加话题”；网页会在正文末尾插入 `#`，软件随后直接在正文内输入关键词，并点击下方完全同名结果。
- 不再由软件手写 `#`，不再使用 Enter 猜测当前候选项；网页刷新正文节点后会重新识别输入位置。
- 话题入口、搜索结果或回读校验失败时禁止提交，避免话题未正确关联仍继续发布。

## 账号独立图片文件夹

- “账号编辑 → 图片与声明”新增“账号图片文件夹（可空）”。
- 填写后，该队列账号从指定图片文件夹及其城市子文件夹取图。
- 留空时继续使用系统设置中的图片总路径，兼容现有配置。
- 队列表导入和导出同步支持“账号图片文件夹”列。

## 验证与发布状态

- 本轮仅安装到 `D:\\软件\\DouyinPublisher` 进行本机验证。
- 真实账号测试限定为账号队列顺序 3，单次只测试 1 条。
- 用户已于 2026-10-08 确认正式上传发布该版本；本仓库不保存服务器凭据或上传操作记录。
