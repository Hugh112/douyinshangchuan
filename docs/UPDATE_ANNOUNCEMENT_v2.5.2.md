# 抖音智能发布中心 v2.5.2 更新公告

发布时间：2026-08-06
更新方式：可选更新，不强制升级

## 升级方式

- v2.5.x 用户可在软件内点击“检查更新”，确认后在线升级。
- 仍使用 v2.3.0 的用户建议下载 v2.5.2 完整安装包升级，可自行选择安装路径；用户配置、发布进度和本机加密授权数据不会写入更新包。
- 软件账号和密码请自行联系各组组长获取。

## 相比 v2.3.0 的最新功能

| 项目 | v2.3.0 | v2.5.2 |
|---|---|---|
| 启动与安装 | 以脚本/VBS 启动为主 | 原生 EXE 与完整安装包，依赖随包提供，支持自定义安装路径和无黑框启动 |
| 软件授权 | 无统一软件账号入口 | 统一授权登录、记住账号、DPAPI 加密记住密码、切换账号、心跳复核和授权变化暂停 |
| 浏览器账号 | 单浏览器/单套公共配置 | 多浏览器队列，同一浏览器可重复出现，勾选哪些账号就发布哪些账号 |
| 内容分配 | 多账号共用内容 | 每个队列项独立图片、Excel、工作表、发布条数和发布进度 |
| 发布时间 | 公共排期 | 每个账号独立立即/定时排期；时间点不足时按该轮时间点循环复用 |
| 队列执行 | 无完整账号轮转 | 掉号自动跳过并切换下一个账号；全部启用账号处理完才结束 |
| 任务续跑 | 重启后可能需要重新处理 | 停止或重启后继续当前轮次，跳过已完成账号并只发布剩余条数 |
| 队列维护 | 手工逐项维护 | 支持 Excel 全表导入/导出、全选/取消、复制、排序和手动列宽持久保存 |
| 自动启动 | 无按星期启动 | 支持自定义星期和时间自动启动 |
| 日志与控制 | 页面布局受限 | 任务控制和运行日志在所有页面固定可见，各页独立滚动 |
| 更新安全 | GitHub 清单更新 | 统一管理后台优先、GitHub Raw 与 jsDelivr 灾备，下载后强制校验 SHA256 |

## 发布稳定性修复

- Excel 有表头和无表头场景都能正确读取第一条文案。
- 正文和话题继续通过浏览器键盘事件逐字输入，不使用剪贴板粘贴正文；话题识别后不留下多余 `#`。
- 已填写正文不再被误判为空，并改进发布完成后进入作品管理页的判断。
- 发布失败按每次任务配置的次数重试；任何原因触发自动暂停都会弹窗提醒。
- 继续保留随机图片、立即发布、多日定时发布、发布成功后按配置删除图片/文案、CDP 后台控制及不主动拉起最小化浏览器。
