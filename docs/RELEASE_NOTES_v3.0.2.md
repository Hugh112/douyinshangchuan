# v3.0.2 更新说明

发布日期：2026-08-10
更新策略：可选更新，不强制升级

## 新增与优化

- 新增可勾选的账号轮换发布，可自定义每个账号连续成功发布几条后切换；默认 1 条时按账号逐条轮转，达到各自配额的账号自动退出轮转。
- 轮换批次精确取账号剩余配额，账号达到切换边界后立即切换，不再额外等待发布间隔。
- 浏览器账号队列支持运行中锁定、暂停后编辑；恢复任务时自动保存顺序、配置、勾选状态和连续发布条数。
- 新增今日投稿上限识别与前端等待秒数；命中后不重试、不消费图片或文案、不增加已发布数量，本次运行跳过该账号。
- 账号运行状态新增已发布数量、最后失败步骤、具体原因和已保留进度；停止、失败或软件重启后继续未完成轮次。
- 调试截图每三次正常启动清理一次，只清理本软件生成的截图，避免长期堆积。
- 发布页控制改为网页模块优先：语义定位、DOM 原生点击、真实鼠标与坐标兜底逐级执行，并在每一步读取实际状态验证。
- 重构音乐选择校验：已有音乐不重复打开面板；推荐/热门新版列表不再依赖“万使用”或固定时长；点击“使用”后等待页面刷新，面板意外关闭时只重试音乐步骤。
- 发布成功必须确认进入作品管理页；仅出现成功提示但未完成跳转时不消费图片、文案或发布进度。
- 发布中心新增“重试勾选失败账号”，账号问题修复后可从保留进度继续。

## 分层重试规则

1. 任一发布步骤失败时，只重新执行该步骤，不回退已完成步骤。
2. “单步骤失败后重试次数”耗尽后，才使用“总体流程失败后重试次数”，重新进入发布页并从上传当前图片开始。
3. 总体重试仍失败时记录最后失败步骤和根因，保留图片、文案、排期及账号累计进度，并跳过当前账号。
4. 账号掉线、需要安全验证或达到今日投稿上限时不进入普通重试。

例如音乐未选中时，程序只重新选择并校验音乐；只有该步骤耗尽次数，才重新上传当前作品。标题、正文话题、图片上传、发布设置、定时设置、最终校验和提交确认等步骤使用同一规则。

音乐调试截图会分别标记“面板未打开、列表未加载、找不到歌曲行、找不到使用按钮、点击后状态未生效”，账号队列同时保留最底层原因和当前进度/配额。

## 保留功能

- 城市子文件夹图片匹配、标题列及旧无表头 Excel 兼容。
- 多浏览器独立 Excel、独立排期、同一浏览器重复入队和队列全表导入/导出。
- 随机图片、逐字输入正文和话题、立即/定时发布、成功后按配置删除内容。
- 软件登录、记住账号/密码、授权心跳、撤权提醒、遥测、SHA256 在线更新和无黑框启动。
