# 抖音智能发布中心 v3.1.2 发布说明

## 话题可靠性修复

- 修复抖音富文本输入后重建活动节点、旧 Locator 将点击前正文误读为空的问题；点击话题前会重新读取当前活动正文和可见正文。
- 实机确认正文和话题写回中包含 `U+200B`、`U+00A0` 及普通空格；比较点击前后正文时会统一剔除这些肉眼不可见字符，只有严格确认正文只新增一个 `#` 才输入话题关键词。
- 每个话题的入口只点击一次；仍未回读到单个 `#` 时立即失败并禁止重复点击，避免形成 `###`。
- 话题仍必须从网页下方候选中点击完全同名结果，不使用 Enter 猜测，也不把手写 `#话题` 当作成功。
- 候选点击后会兼容读取网页重建前后的正文节点；任一话题未最终回写到正文时禁止提交。

## 实机验证

- 使用本机账号队列顺序 3“湖南2”进入图文发布页并上传隔离测试图片，只验证到发布按钮之前。
- `#岳阳县`、`#亲子鉴定`、`#亲子鉴定中心` 均点击完全同名候选，最终正文回读校验为 3/3。
- 验证结束后关闭测试页和本轮启动的浏览器，未点击最终发布按钮。

## 兼容与数据保护

- 完整保留 v3.1.1 的账号独立图片文件夹功能及全部既有发布、重试和进度逻辑。
- 更新不覆盖 `%LOCALAPPDATA%\DouyinPublisher` 中的配置、授权、登录偏好和发布进度，也不修改用户图片或 Excel。
