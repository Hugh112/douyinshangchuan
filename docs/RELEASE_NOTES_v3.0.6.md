## 修复内容

- 修复部分电脑在音乐抽屉没有打开时，因分辨率、缩放或页面 DOM 布局差异而把普通空音乐模块误判为“音乐面板已打开”的问题。
- 音乐入口采用双层定位：先使用当前语义定位、DOM 原生点击和元素边界真实鼠标点击；严格确认抽屉仍未打开时，再完整执行 v3.0.1 已验证的音乐行识别、行右侧区域和文字矩形点击流程。
- v3.0.1 逻辑只负责打开音乐面板；歌曲列表识别、“使用”按钮、面板滚动和音乐生效校验继续使用新版规则，并且全部限制在已确认的音乐抽屉根节点内。
- 修复“进度文件/发布日志”填写为目录时出现 `Permission denied` 的问题；目录内自动使用固定 JSON/CSV 文件名。已确认发布成功后先保存数量和进度，CSV 日志失败不再把任务改成失败。
- 城市图片子文件夹增加市、州、自治州、区、县、自治县、盟、旗等行政区后缀别名匹配；精确名称优先，短名歧义时提示填写完整名称。
- 修复勾选“启动前关闭 Chrome 残留”后误杀 Playwright Node 驱动导致 `Connection closed while reading from the driver` 的问题；现在只清理 Chrome，并且清理发生在浏览器控制驱动启动之前。
- 修复轮换模式多个快捷方式没有显式用户目录时共用同一 Chrome 目录、后续 CDP 端口无法建立的问题；自动生成稳定隔离目录，相同浏览器和端口仍可复用。
- 在线更新器增加可见进度窗口，显示下载百分比、下载大小、SHA256 校验、ZIP 检查、解压、安装和重启状态。
- 下载异常时显示重试次数和失败原因，避免用户把等待过程误认为更新器失效。
