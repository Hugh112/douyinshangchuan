# 抖音智能发布中心 v3.0.9 更新说明

## 多图规则修正

- 每条作品可按账号设置一次上传 1—35 张图片。
- 同一条作品一次上传的 N 张图片保证互不重复，不会把同一图片在本条作品中上传多次。
- 发布下一条作品时，会重新从完整图片库随机或按名称顺序选择，允许循环使用之前的图片。
- 勾选“发布成功后删除图片”时，只有确认发布成功后才删除本条图片；未勾选时图片继续保留在图片库。
- 步骤重试和总体流程重试继续使用当前作品已选定的同一批图片，不会在重试过程中换图。

## 兼容说明

- v3.0.9 忽略 v3.0.8 曾写入的图片历史占用记录，升级后不需要重置发布进度。
- 保留账号级多图数量、随机/名称顺序、可配置发布声明，以及原有多浏览器、轮换发布、暂停恢复和独立进度功能。
- 本候选包未修改线上更新清单或统一管理后台，需先完成测试后再推送。
